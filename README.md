### 🧬 2. AI-Based Early Alzheimer's Detection from EEG Signals
**AI Research Project**

A research-oriented project exploring the use of EEG signal processing and Artificial Intelligence for early detection of Alzheimer's-related patterns.

**🔬 Key Work**
- EEG signal preprocessing
- EEG data analysis
- Statistical feature extraction
- Entropy-based features
- Frequency-domain analysis
- Frequency band power analysis
- Delta, Theta, Alpha, Beta and Gamma bands
- Machine Learning classification
- Neural Network-based classification
- Model evaluation

**🧠 Models:** Random Forest · Neural Network / CNN-based approach

**📊 Results**

| Model | Accuracy |
|---|---|
| Random Forest | ~70% |
| Neural Network | ~73% |

**📚 Dataset:** OpenNeuro — ds004504

**🛠️ Technologies:** Python · MNE · NumPy · Pandas · Scikit-learn · Deep Learning · EEG Signal Processing

### 🐄 3. AI-Powered Cattle Disease Detection with Visual Explainability
**Computer Vision + Explainable AI**

A deep learning-based computer vision system for cattle disease detection using image classification and visual explainability.

**🔥 Key Work**
- Image preprocessing
- Dataset preparation
- Image classification
- Transfer learning
- ResNet50
- Model evaluation
- Explainable AI
- Grad-CAM visualization
- Region-of-interest verification

**🧠 Model:** ResNet50 Transfer Learning

**🔍 Explainability:** Grad-CAM was used to visualize the image regions influencing the model's predictions and verify whether the model was focusing on meaningful regions.

**🛠️ Technologies:** Python · TensorFlow · Keras · OpenCV · ResNet50 · Computer Vision · Grad-CAM
