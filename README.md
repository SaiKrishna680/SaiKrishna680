## Featured Projects

### 🧠 Multimodal Document Intelligence & RAG System
Built an end-to-end Retrieval-Augmented Generation system: documents are processed, chunked, embedded, and stored in a vector store, then retrieved at query time to ground an LLM's answers in the actual source material instead of letting it hallucinate.

`Python` `LLMs` `RAG` `Embeddings` `Vector Search` `Full-Stack`

### 🧬 Early Alzheimer's Detection from EEG Signals
Research project applying signal processing and ML to EEG data for early detection of Alzheimer's-related patterns — covering frequency-band feature extraction (Delta/Theta/Alpha/Beta/Gamma) and classification.

**Random Forest: ~70% accuracy · Neural Network: ~73% accuracy** on OpenNeuro dataset ds004504

`Python` `MNE` `Scikit-learn` `Deep Learning` `EEG`

### 🐄 Cattle Disease Detection with Visual Explainability
Deep learning image classifier (ResNet50, transfer learning) for cattle disease detection, paired with Grad-CAM to visualize and verify which regions of the image the model was actually using to make predictions.

`Python` `TensorFlow` `Keras` `OpenCV` `ResNet50` `Grad-CAM`

### 🌐 Wanderlust — Hotel Booking Web App
Full-stack MERN application with REST APIs, MongoDB data modeling, and a complete booking flow from backend to UI.

`MongoDB` `Express` `React` `Node.js`
